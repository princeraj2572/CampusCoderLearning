# Student learning roadmap: content

All the content from the CampusCoders roadmap, exported for reuse.

## Layout

- `ALL-CONTENT.md`: everything in one file, in reading order.
- `content/NN-*.md`: one Markdown file per topic page, numbered in reading order.
- `content/roles/*.md`: one file per role.
- `data/roadmap.json`: the same content as structured data (groups, pages, roles).
